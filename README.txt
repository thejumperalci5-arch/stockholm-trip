STOCKHOLM TRIP V14 — IPHONE POLISH

Base: V13 audited budget.

Pulido realizado:
- safe-area superior e inferior para iPhone con notch/Dynamic Island.
- uso de 100svh para Safari móvil.
- botones táctiles de mínimo ~52 px.
- feedback visual al pulsar.
- microanimación al seleccionar opciones.
- entrada más suave de cada pantalla.
- MATCH/NO MATCH con aparición más contundente.
- cuenta atrás mejorada.
- cartas optimizadas para interacción táctil.
- overlays con scroll si la pantalla es pequeña.
- ajustes específicos <= 390 px.
- evita dobles pulsaciones accidentales en botones principales.
- vibración suave cuando el navegador/dispositivo la soporte.
- respeta “Reducir movimiento” de iOS.
- mantiene presupuesto auditado, conversiones SEK/EUR y secretos ocultos.

Siguiente prueba recomendada:
recorrer TODO el cuestionario en Safari de iPhone y anotar cualquier pantalla
que requiera scroll incómodo, texto cortado o botón difícil de pulsar.
